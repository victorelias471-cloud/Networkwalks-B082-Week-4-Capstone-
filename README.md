## 🧪 Testing Methodology

The assessment was performed in a structured manner:

### Phase 1 – Reconnaissance

Activities included:

- Identifying publicly accessible application components.
- Reviewing available pages and resources.
- Examining HTTP responses and headers.
- Identifying potentially interesting directories and files.

### Phase 2 – Application Testing

Activities included:

- Testing authentication functionality.
- Reviewing input handling.
- Testing authorization controls.
- Checking for common web application weaknesses.

### Phase 3 – Information Exposure

Activities included:

- Reviewing publicly accessible files.
- Checking for exposed configuration or backup files.
- Reviewing metadata where appropriate.
- Assessing whether sensitive information was unnecessarily exposed.

### Phase 4 – Findings and Recommendations

The final phase involved documenting confirmed observations, explaining their potential impact, and providing remediation recommendations.
